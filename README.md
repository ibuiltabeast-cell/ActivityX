# ActivityX

A sleek and lightweight activity & habit tracking application.

## Features

- **Web App**: Clean, responsive single-page web app (`index.html`) with dark/light mode, real-time statistics, category filtering, search, and local persistence.
- **Node.js CLI**: Quick console greeting and verification script.

## Getting Started

### 1. Web Application
Simply open `index.html` directly in your browser:
- Double-click `index.html` in your file explorer, or
- Start a simple local static server (e.g., `npx serve .` or `python -m http.server 3000`).

### 2. Node.js Script
```bash
node hello_world.js
```
